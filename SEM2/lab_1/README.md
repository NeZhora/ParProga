# Лабораторная 1. Умножение квадратных матриц

| Пункт | Метод в CSV | Реализация |
|---|---|---|
| 1 | `naive` | Три цикла `i, j, k`. Элементы столбца `B` читаются с шагом `N`. |
| 2 | `transposed` | Транспонирование `B`. В скалярном произведении обе строки читаются последовательно. |
| 4 | `strassen` | Семь произведений подматриц вместо восьми. Ниже порога рекурсии используется умножение с транспонированием. |
| 5 | `transposed_omp` | OpenMP распределяет строки транспонированной `B` и строки результата. Между этапами действует барьер. |
| Сдача | `strassen_omp` | Те же листья с транспонированием. На верхнем уровне семь произведений считаются независимо, результат собирается по строкам параллельно. |

Для Штрассена размер округляется вверх до степени двойки с дополнением нулями. Порог по умолчанию равен 64. На размерах до порога параллельный Штрассен использует тот же OpenMP-алгоритм, что и `transposed_omp`. Выше порога основная фаза делится на семь задач, поэтому восьмой поток может простаивать. Асимптотическая сложность наивного алгоритма составляет `O(N³)`, у Штрассена она равна `O(N^log₂7)`.

На допуске проверяется произведение двух матриц из единиц размера 512. Все элементы ответа должны быть равны 512. Для остальных замеров входные данные одинаковы для всех методов, а каждый элемент ответа сверяется с наивным умножением.

## Запуск на кластере

Из корня копии репозитория на головном узле:

```sh
cd SEM2/lab_1
make
sbatch run_matmul.sh
squeue --me
```

Задание занимает один узел и запрашивает восемь CPU для одного процесса. В `matmul-<id>.out` будет CSV, а сообщения об ошибках попадут в `matmul-<id>.err`. Скрипт делает три повтора на размерах `32 64 128 256 512 1024`. Например, чтобы проверить влияние порога и добавить размер 2048:

```sh
SIZES='512 1024 2048' REPEATS=1 CUTOFF=128 sbatch run_matmul.sh
```

Отдельный прогон после сборки: `./matmul 257 3 4 64`. Аргументы задают размер, число повторов, максимальное число потоков и порог Штрассена.

## Обработка результатов

Время в CSV — медиана повторов. Оно включает транспонирование и, где нужно, дополнение и обрезку матриц для Штрассена. Выделение памяти, заполнение входов и проверка ответа выполняются вне замера. Ускорение `S = T_seq/T_p` считается относительно соответствующей последовательной версии, эффективность `E = S/p`.

На машине с Python 3.9+ и Matplotlib 3.6+ из папки `SEM2/lab_1`:

```sh
python3 ../plot_benchmarks.py matrix matmul-123.out --out plots
```

Подставьте номер задания вместо `123`. В `plots` появятся графики времени, ускорения и эффективности в зависимости от размера матриц.
